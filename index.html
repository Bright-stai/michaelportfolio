How I work

Fix it with the developers

Findings come with severity, evidence and remediation guidance. I apply STRIDE threat modeling at design stage, so whole classes of issues never get built.

Make security the default

SAST before release, DAST after deployment, dependency and secrets scanning, and a protected-branch workflow so nothing reaches production without clearance.

Guided by OWASP Top 10, MITRE ATT&CK and NIST CSF.
